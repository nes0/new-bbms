Fake machine reader

Talks to this server through the v2 device API (/api/devices/v2/), as new firmware would. Create a demo machine, reader and fobs with DEBUG=True .venv/bin/python manage.py create_demo_device, then paste the key it prints.

The relay cuts the machine's supply, so the reader only measures current while it's on.
