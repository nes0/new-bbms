# Policies

The space's policies as markdown, shown on the site (spec 06 §6.8). Changes are reviewed in a pull request.

Copied from the legacy system (`resources/polices/`) on 2026-11-08. Changes since: nested lists indented by four
spaces (so they render as nested lists), and links to pages the new site doesn't have yet removed (the rules link
now points to the rules on the same page; Slack, which is no longer used, is now Discord, as in the rules).

The other six (code of conduct, grievance procedure, trusted member, permaloan, 3 week bins, member storage) were
copied on 2026-11-09 with the wording unchanged; only `#Heading` became `# Heading` and a blank line was added before
lists, so they render. Their file names are the addresses on `/resources/policy/<name>/`; a new policy also needs a
line in `CORE_RULES` or `OTHER_POLICIES` in `apps/core/policies.py`.
